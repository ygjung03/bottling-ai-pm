## V8. 소상공인시장진흥공단 상가(상권)정보 — 완료

### 호출 규격

```
GET https://apis.data.go.kr/B553077/api/open/sdsc2/storeListInRadius
```

| 파라미터 | 값 | 비고 |
|---|---|---|
| `serviceKey` | 공공데이터포털 키 | 발급 시 키가 1개만 제공된다 (Encoding/Decoding 구분 없음) |
| `cx` | `127.0679483` | 경도 (바틀링) |
| `cy` | `37.5318919` | 위도 (바틀링) |

> **바틀링 좌표** — 광진구 뚝섬로34길 67 기준 `37.5318919, 127.0679483`.
> 초기 설정값(37.5305, 127.0664)은 주소만 보고 추정한 값이었으며 약 200m 오차가 있어 2026.8.23 정정했다. `.env`의 `BOTTLING_LAT` / `BOTTLING_LNG`도 함께 갱신할 것.
| `radius` | `1000` | 미터 |
| `indsLclsCd` | `I2` | 음식 대분류 |
| `numOfRows` | `1000` | 최대치 확인됨 |
| `pageNo` | `1` | |
| `type` | `json` | |

### 검증 결과

| 확인 항목 | 결과 |
|---|---|
| 반경 조회 | `cx`·`cy`·`radius` 정상 동작 |
| **업종 필터** | `indsLclsCd=I2` 적용 시 **2,089건 → 540건** |
| **페이징** | `numOfRows=1000` 그대로 적용됨. 540건이 한 번에 수신 → **페이징 불필요** |
| 좌표 | `lon`·`lat` (숫자형) |
| 기준 시점 | `stdrYm: 202606` (2026년 6월) |

**응답 구조**

```
header
  stdrYm, resultCode, resultMsg, columns[]
body
  items[]        점포 배열
  numOfRows      요청한 개수
  pageNo         페이지 번호
  totalCount     조건에 맞는 전체 개수
```

> `totalCount`는 **조건 전체 개수**, `numOfRows`는 **이번 응답에 담긴 개수**다. 540 < 1000이므로 1페이지에 전부 수신된다.

### 스키마 매핑 (`nearby_stores`)

**스키마 수정 불필요.** 설계한 컬럼이 모두 대응된다.

| 스키마 컬럼 | API 필드 | 예시 |
|---|---|---|
| `store_id` | `bizesId` | MA010120220800016948 |
| `name` | `bizesNm` | 놀부부대찌개스타시티점 |
| `category_l` | `indsLclsNm` | 음식 |
| `category_m` | `indsMclsNm` | 한식 |
| `category_s` | `indsSclsNm` | 국/탕/찌개류 |
| `address` | `rdnmAdr` | 서울특별시 광진구 아차산로 262 |
| `lat` | `lat` | 37.5370075870311 |
| `lng` | `lon` | 127.072956203815 |
| `distance_m` | (직접 계산) | 바틀링 좌표 기준 |

**적재하지 않는 필드** — 지번주소, PNU코드, 우편번호, 건물관리번호, 층/호 정보 등은 사용처가 없다. 필요해지면 재수집한다.

### 업종 분류 확인

**`indsLclsCd=I2`(음식) 하나로 충분하다.** 카페·제과가 모두 이 안에 있다.

| 대분류 | 중분류 | 소분류 | 검색 결과 |
|---|---|---|---|
| I2 음식 | `I201` 한식 | 국/탕/찌개류 등 | – |
| I2 음식 | **`I210` 기타 간이** | **빵/도넛**, 피자 | 제과점업 23건 |
| I2 음식 | **`I212` 비알코올** | **카페** | 카페 115건 |

> **협업 후보로 유효한 것은 `I210`·`I212`다.** 붕어빵·떡·베이커리·카페가 여기 속한다.
> 명세서 3-3 상보성 매핑표의 「제과·디저트 1.0」이 이 두 중분류에 대응된다.

**제외 대상 대분류** — 필터 없이 조회하면 아래가 섞여 들어온다.

```
I1 숙박 · M1 과학·기술 · P1 교육 · S2 수리·개인 · G2 소매
```

### 남은 판단

- **붕어빵·떡 노점형이 `G2`(소매)에 있을 가능성**이 있다. `I2`만 쓰면 놓칠 수 있다.
  → 필터 없이 2,089건을 받아 중분류로 직접 거르는 방안도 가능하다. 건수 차이가 크지 않아 부담은 없다.
- 반경 1km에 **성동구 성수동이 포함**된다. 사업계획서의 "광진구·성수동 로컬 크리에이터 협업"과 부합하므로 제외하지 않는다.

## V9. 서울시 문화행사 정보 — 완료

### 호출 규격

```
GET http://openapi.seoul.go.kr:8088/{KEY}/json/culturalEventInfo/{시작}/{끝}/
```

### 검증 결과

| 확인 항목 | 결과 |
|---|---|
| 자치구 필드 | **`GUNAME`** (예: 광진구) |
| 위경도 | **`LOT`(경도) · `LAT`(위도)** — 문자열로 옴 |
| 날짜 | `STRTDATE` · `END_DATE` — `2026-12-24 00:00:00.0` 형식 |
| 표시용 기간 | `DATE` — `2026-12-24~2026-12-24` |
| 유무료 | `IS_FREE` — "유료" / "무료" |
| 링크 | `HMPG_ADDR` |
| 전체 건수 | **19,503건** |

> ⚠️ **`LOT`이 경도(longitude)다.** 통상 `LON`을 쓰므로 혼동하기 쉽다.

### [주의] 요청 파라미터 필터가 동작하지 않는다

자치구·날짜를 URL 경로에 넣어 시도했으나 **모두 전체 19,503건이 반환**되었다.

```
.../1/5//광진구/          → 19,503건 (필터 무시)
.../1/5///2026-08-23      → 19,503건 (필터 무시)
```

문서상 요청 인자는 `CODENAME`(분류) · `TITLE`(행사명) · `DATE`(날짜)뿐이며, **`GUNAME`은 응답 전용 필드**다.

**→ 전체를 받아 코드에서 필터링한다.**

- 1,000건씩 약 20회 호출
- **일 1회 배치**이므로 부담 없음

### 필터링 방침

**자치구가 아니라 좌표 기준으로 거른다.**

| 조건 | 값 |
|---|---|
| 반경 | 바틀링 좌표 기준 **3km** |
| 기간 | `STRTDATE` ~ `END_DATE`가 **향후 30일과 겹치는 것** |

> 자치구(`GUNAME`) 필터보다 좌표 필터가 낫다. 뚝섬 건너편 **성동구 성수동** 행사도 포함되며, 이는 사업계획서의 "광진구·성수동 로컬 크리에이터 협업"과 부합한다.

### 스키마 매핑 (`events`)

| 스키마 컬럼 | API 필드 |
|---|---|
| `source` | `'seoul_api'` (고정) |
| `title` | `TITLE` |
| `place` | `PLACE` |
| `start_date` | `STRTDATE` (앞 10자) |
| `end_date` | `END_DATE` (앞 10자) |
| `lat` | `LAT` (문자열 → float) |
| `lng` | **`LOT`** (문자열 → float) |
| `distance_m` | 직접 계산 |
| `is_free` | `IS_FREE == "무료"` |
| `url` | `HMPG_ADDR` |

**스키마 수정 불필요.**

## V10. 광진구청 게시판 — 완료

### robots.txt 확인 결과

```
User-agent: *
Crawl-delay: 10
Disallow: /
Allow: /portal/bbs/B0000001      ← 새소식
```

| 게시판 | 경로 | 허용 |
|---|---|---|
| **새소식** | `/portal/bbs/B0000001` | **허용** |
| 축제·행사정보 | `/portal/bbs/B0000211` | **금지** (Allow 목록에 없음) |

> **`Crawl-delay: 10`** — 요청 간 10초 간격 필수. 코드에 `time.sleep(10)`을 반드시 넣는다.
> 축제·행사정보 게시판은 사용하지 않는다. 새소식만으로 충분하다.

### 수집 방식 — 검색 URL 활용

전체 3,514건을 훑을 필요 없이 **검색 파라미터로 4건만** 받는다.

```
GET https://www.gwangjin.go.kr/portal/bbs/B0000001/list.do
    ?menuNo=200190&pageIndex=1&searchCnd=1&searchWrd=문화행사
```

「문화행사」 검색 결과 **4건**, 전부 문화예술과의 주간 안내 글이다. 페이징 불필요.

### 제목 규칙

```
다음주(8/24~8/30) 문화행사 안내
다음주(8/17~8/23) 문화행사 안내
다음주(7/27~8/2) 문화행사 안내
```

정규식으로 기간 추출이 가능하다.

```
다음주\((\d+)/(\d+)~(\d+)/(\d+)\) 문화행사 안내
```

게시 주기는 **주 1회**(주 후반). 게시일 예: 8/21(금), 8/12(수), 7/23(목).

### 상세 페이지 구조

```
GET .../view.do?nttId={게시물ID}&menuNo=200190
```

**HTML 표로 작성되어 있으며 PDF 첨부가 아니다.** 파싱 가능하다.

행사별로 번호가 붙고, 항목이 `<table>`의 `행 제목 | 값` 구조로 반복된다.

```
6. 2026 광진 뮤직 페스타 개최
   일   시   2026. 8. 29.(토) 13:00 ~ 21:00
   장   소   자양역 2·3번 출구 일대(뚝섬 한강공원)
   대   상   광진구민 누구나
   내   용   재즈·락·트로트 음악 공연 / 플리마켓·체험부스·푸드트럭
   출 연 진   ...
   문   의   ...
```

항목명은 행사 성격에 따라 다르다(`교육명`·`모집기간`·`교육대상` 등). **`일시`·`장소`만 필수로 뽑고 나머지는 본문으로 합친다.**

### [중요] V10이 필요한 이유

위 예시의 **「2026 광진 뮤직 페스타」(8/29, 뚝섬 한강공원, 푸드트럭·플리마켓)**는 바틀링 상권에 직접 영향을 주는 행사다. 서울시 문화행사 API(V9)에는 이런 구청 주최 행사가 누락될 가능성이 높다.

→ **V9(시 단위)와 V10(구 단위)은 상호 보완 관계이며 둘 다 필요하다.**

### 스키마 매핑 (`events`)

| 스키마 컬럼 | 출처 |
|---|---|
| `source` | `'gwangjin_board'` (고정) |
| `title` | 행사 제목 (번호 제외) |
| `place` | `장소` 행 |
| `start_date` · `end_date` | `일시` 행에서 파싱 |
| `lat` · `lng` | **없음** — 장소명 기반 판단 필요 |
| `is_free` | 대체로 무료. 명시 없으면 NULL |
| `url` | 상세 페이지 주소 |

> **좌표가 없다.** V9와 달리 반경 필터를 못 쓴다. 장소명에 `뚝섬`·`자양`·`한강공원`이 포함되는지로 1차 판단하고, 애매하면 전부 넣는다. 구청 행사는 어차피 광진구 내이므로 범위가 좁다.

| JSON 강제 출력 | `response_mime_type: application/json` 정상 |

> ⚠️ **응답 시간이 명세서 추정(12초)보다 길다.** 실제 프롬프트는 상권 데이터·협력사 자원·제약·few-shot이 모두 들어가고 3안을 요구하므로 **4단계 합계가 2분에 근접할 가능성**이 있다. 화면 설계(4-2) 재검토가 필요하다.
