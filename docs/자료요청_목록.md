# PART 1. 서형원 대표님께 요청

## A. 즉시 필요 (～8/23) — 없으면 개발 착수 불가

### A-1. 맥주 라인업 상세

네이버 지도에서 **메뉴명과 단가(원/ml)는 확보**했습니다. 아래만 추가로 부탁드립니다.

| 항목 | 상태 | 왜 필요한가 |
|---|---|---|
| 스타일 (라거·IPA·위트에일 등) | 7종은 **이름으로 짐작**, 5종은 전혀 모름 | 음식 페어링의 1차 기준 |
| 도수 (ABV) | 전체 미확인 | 강한 안주 / 가벼운 안주 매칭 |
| 맛 특성 (과일향·고소함·산미·바디감) | 전체 미확인 | **콜라보 메뉴 개발의 핵심 입력** |
| IBU (쓴맛) | 미확인 | 있으면 좋음, 없어도 진행 가능 |
| 교체 주기·방식 | 미확인 | 월 1회 전량 교체인지, 일부만인지 |

**전혀 모르는 5종** — `맘마미아 ｜ 캄캄 ｜ 끽비어 삐약 ver2 ｜ 빅웨이브 ｜ 흔들흔들`

> 나머지 7종도 `갈매기 IPA → IPA`처럼 **이름을 보고 짐작한 것일 뿐 확인받은 것이 아닙니다.**
> 별도 작성용 폼(`바틀링_자료요청서_1차`)에 저희 짐작을 미리 채워두었으니 틀린 것만 고쳐주시면 됩니다.

> **작성 예시** (형식 참고용, 실제 값 아님)
>
> ```
> 갈매기 IPA      / 6.5도 / IPA / 시트러스향 강함, 쓴맛 진함 / 튀김·매운맛과 잘 맞음
> 워터멜론 위트에일 / 4.5도 / 위트에일 / 수박향, 달달하고 가벼움 / 디저트류와 잘 맞음
> 바틀링 라거     / 4.8도 / 라거 / 깔끔하고 청량함 / 뭐든 무난하게 어울림
> 맘마미아        / 5.2도 / 세종 / 새콤하고 드라이함
> ```
>
> **교체 주기 예시**: "월초에 4～5종 정도 바꾸고, 바틀링 라거랑 산토리는 고정으로 둡니다"

> 대표님이 큐레이션하시는 분야라 구두로도 충분합니다. **메모·사진·음성 무엇이든** 괜찮습니다.

### A-2. 주방·매장 조리 여건

| 항목 | 작성 예시 |
|---|---|
| 사용 가능한 조리기구 | "전자레인지, 에어프라이어 있고 인덕션은 1구 있습니다" |
| **화기 사용 가능 여부** | "가스는 못 쓰고 전기만 됩니다" / "건물 규정상 불 사용 불가" |
| 냉장·냉동 보관 용량 | "냉장고 1대, 냉동칸은 작아서 하루치 정도만" |
| **1인 운영 중 조리 수준** | "손님 몰릴 땐 5분 넘는 조리는 무리입니다. 데우거나 담는 정도만 가능" |
| 외부 공간·전기 | "매장 앞에 테이블 2개 놓을 자리 있고, 외부 콘센트 1구 있습니다" |

> AI가 "매장에서 즉석 조리하는 메뉴"를 제안했다가 실제로 불가능한 경우를 막기 위한 정보입니다.
> **못 하는 것을 알려주시는 게 할 수 있는 것보다 중요합니다.**

### A-3. 협업에 쓸 수 있는 장비

**A-2와의 구분** — A-2는 매장에 **이미 있어 상시 쓰는** 장비, A-3은 **협업할 때 따로 준비해야 하는** 장비입니다.

| 항목 | 왜 필요한가 |
|---|---|
| **보유 / 대여 구분** | 이미 있으면 준비 기간이 0일입니다 |
| **이동 가능 여부** | 못 옮기면 협업 장소가 협력사 매장이 됩니다. 실행 방식이 통째로 달라집니다 |
| **예약 리드타임** | 기획안의 준비 기간 제약과 직결됩니다 |

> **작성 예시**
>
> ```
> 붕어빵기계    / 대여 / 2인이 들면 됨 / 3일 전
> 화덕피자오븐  / 보유 / -           / -
> ```

> 사업계획서에 화덕피자오븐·붕어빵기계·맥주 셀프탭이 기재되어 있으나, **맥주 셀프탭은 매장 상시 설비로 판단해 제외**했습니다. 화덕피자오븐이 상시 보유인지 대여인지는 미확인입니다.

### A-4. 협력사 명단 [중요]

사업계획서 명시: **소상공인 2개사 + 조리기구 대여 3개사 섭외 완료**

> **작성 예시**
>
> ```
> [소상공인]
> 떡붕 / 붕어빵·떡 / 자양동 (도보 5분) / 사장님 010-0000-0000 / 9월 초 가능
> OO피자 / 화덕피자 / 성수동 / 담당 김OO / 10월부터 가능
>
> [장비 대여]
> OO주방설비 / 화덕오븐·붕어빵기계 / 광진구 / 010-0000-0000
> ```
>
> **추가로 알려주시면 좋은 것**
> - "떡붕 사장님이랑은 이미 얘기 끝났고 9월 둘째 주부터 가능합니다"
> - "OO피자는 아직 구체적으로 말 안 꺼냈습니다"
> - 링크 보내도 되는지: "떡붕은 바로 보내셔도 되고, OO피자는 제가 먼저 얘기할게요"

> 9월 중 최소 1건을 실제로 실행해야 10월 최종보고서에 결과 수치가 들어갑니다.
> **가장 빨리 움직일 수 있는 한 곳**만 먼저 알려주셔도 됩니다.

## B. 1주 내 (～8/30)

### B-1. 기존 협업 3건 자료

**떡붕 · YARR 화덕피자 · 카페 위켄드**

**필수** — 없으면 AI가 참고할 사례가 없습니다

| 항목 | 작성 예시 |
|---|---|
| 실행된 최종 메뉴 | "슈크림 붕어빵 3개 + 맥주 500ml 세트 / 12,000원" |
| 협업 상대의 자원·담당 | "떡붕이 붕어빵 완제품 납품, 저희는 맥주랑 자리 제공. 정산은 5:5" |
| 준비 소요 기간 | "얘기 꺼내고 실제 판매까지 열흘 정도 걸렸습니다" |
| **잘 안 된 점** [중요] | "붕어빵이 식으면 맛이 떨어져서 회전이 빨라야 했는데, 평일엔 손님이 적어 재고가 남았습니다. 다시 한다면 주말에만 할 것 같습니다" |

**선택** — 있으면 품질이 올라가지만 없어도 진행 가능

| 항목 | 작성 예시 |
|---|---|
| Gemini 대화 로그 | 캡처 몇 장이면 충분합니다 |
| 매출 변화 | "그 주에 푸드 매출이 평소보다 3～4배 나왔습니다" |
| 콘텐츠 성과 | "릴스 하나가 1만2천 조회 나왔습니다" |

> **"잘 안 된 점"이 가장 중요합니다.** AI에게 "이런 건 피하라"를 알려주는 재료가 되며,
> 성공 사례만 주는 것보다 효과가 큽니다. **기억나시는 대로 편하게** 적어주시면 됩니다.

### B-2. 성과 측정 방식

> **POS 원본 데이터는 요청하지 않습니다.** 협업 성과를 보는 데는 아래 세 가지면 충분합니다.

**(1) 쿠폰 앱 (자체 앱)** — 가장 중요합니다

매장에서 운영 중인 쿠폰 적립 앱에 대해 여쭙습니다.

| 질문 | 작성 예시 |
|---|---|
| 앱 이름과 적립 방식 | "자체 제작 앱이고, 결제하면 1회 적립됩니다" |
| **신규 손님과 재방문 손님이 구분되나요** | "구분됩니다" / "적립 횟수로만 보입니다" / "모르겠습니다" |
| **기간을 정해서 조회할 수 있나요** | "일별로 봅니다" / "월 단위만 됩니다" |
| 사장님 화면에서 볼 수 있는 숫자 | "총 적립 건수, 회원 수 정도" |
| 데이터 내보내기 | "엑셀로 안 되고 화면 캡처만 가능합니다" |
| 실제 이용률 체감 | "손님 절반 정도는 쓰시는 것 같습니다" |

> **왜 필요한가**: 협업 이벤트로 온 손님이 **다시 오는지**를 보려고 합니다.
> 대표님 과제가 비수기 극복이신 만큼, 일회성 화제로 끝나는지 단골이 되는지가 핵심 지표입니다.
>
> [주의] **개인 정보는 필요 없습니다.** "신규 몇 명, 재방문율 몇 %" 같은 **합계 숫자만** 있으면 됩니다.

**(2) NFC키링** (사업계획서 기재)

| 질문 | 작성 예시 |
|---|---|
| 현재 사용 중인가요 | "아직 제작 전입니다" / "일부 손님이 쓰십니다" |
| 사용 이력이 기록되나요 | "충전·사용 내역이 남습니다" |

**(3) 협업 건별 성과** — 실행할 때마다, 구두로도 충분합니다

| 항목 | 작성 예시 |
|---|---|
| 실행일 총매출 | "42만원" |
| 직전 같은 요일 총매출 | "지난주 금요일은 28만원" |
| 인스타 인사이트 | 캡처 1장 (도달·저장·공유 수) |
| 쿠폰 앱 신규 적립 수 | "그날 신규가 8명이었습니다" |

### B-3. SNS 운영 현황

> **작성 예시**
>
> - 팔로워: "인스타 2,400명 정도"

> - 촬영·편집: "제가 직접 하는데 시간이 없어서 자주 못 올립니다"

### B-4. 원가·가격 기준

> **작성 예시**
>
> - 목표 원가율: "안주는 35% 안쪽으로 맞추려고 합니다"

## C. 9월 중 협조 요청

AI 기획안을 5개 항목으로 채점하려 합니다. 기준이 대표님 감각과 맞는지 봐주십시오.

```
실행 가능성 ｜ 자원 정합성 ｜ 페어링 적절성 ｜ 홍보 실효성 ｜ 참신성
```

> **작성 예시**
> - "참신성은 저한테 별로 안 중요합니다. 실행 가능한 게 훨씬 중요해요"
> - "원가보다는 맥주가 얼마나 팔리느냐가 핵심입니다"

### C-3. 결과 기록 협조 (9월 하순～10월) [중요]

**협업 1건당 약 3분**입니다. 이 기록이 다음 기획안의 재료가 됩니다.

| | 항목 | 작성 예시 | 소요 |
|---|---|---|---|
| **필수** | 채택/폐기 + 이유 한 줄 | "폐기 — 준비가 일주일이나 걸려서" | 30초 |
| **필수** | AI 제안과 달라진 점 | "AI는 매장 조리라고 했는데 완제품 받아서 냈습니다" | 1분 |
| **필수** | 실행일 전후 매출 | "실행일 42만원 / 직전 금요일 28만원" | 1분 |
| 선택 | 문제·반응·사진 | "손님들이 사진 많이 찍어갔습니다" | – |

# PART 2. 협력사께 요청

## 전달 방식

대표님께 **협력사별 전용 링크**를 드립니다. 링크를 카톡으로 전달해 주시면, 협력사가 직접 입력합니다.

```
예시: https://bottling-ai.streamlit.app/협력사_입력?code=A7K2
```

- **회원가입·로그인 없음.** 링크만 누르면 바로 입력 화면
- **작성 소요 약 3분** — 선택지가 미리 채워져 있어 타이핑이 적습니다
- 나중에 같은 링크로 **수정 가능**

## 입력 항목 (9개)

| # | 항목 | 필수 | 작성 예시 | 왜 필요한가 |
|---|---|---|---|---|
| 1 | 가게 이름 | O | 떡붕 | 기획안 본문 |
| 2 | 업종 | O | 제과·디저트 | 협업 궁합 판단 |
| 3 | 대표 메뉴 | O | 슈크림 붕어빵, 팥 붕어빵 | 협업의 축 |
| 4 | **보유 식재료** | O | 팥앙금, 슈크림, 붕어빵 반죽, 우유 | **이 안에서만 메뉴를 구성합니다** |
| 5 | **보유 장비** | O | 붕어빵 기계 (이동 가능), 반죽기 (매장 고정) | 조리 가능 범위 결정 |
| 6 | 협업 가능 형태 | O | 팝업 출장 / 재료 납품 | 실행 방식 결정 |
| 7 | 가능 일정 | O | 주중 오후 2～6시 | 실행일 판단 |
| 8 | SNS 채널·팔로워 | - | 인스타 @ddeokbung, 3,200명 | 홍보 도달 추정 |
| 9 | **절대 불가 조건** | O | 주말 출장 불가 / 반죽은 당일 소진 필요 | **AI가 반드시 지킬 제약** |

> **4·5·9번이 결정적입니다.**
> 4번이 부실하면 없는 재료로 메뉴를 만들고, 5번이 없으면 못 쓰는 장비를 전제하며,
> 9번이 비면 지킬 수 없는 조건을 제안합니다.

**4·5·9번 작성 요령**

| | 이렇게 쓰면 좋습니다 | 이렇게 쓰면 곤란합니다 |
|---|---|---|
