# 협력사 입력 구글폼 문항 (T21)

**작성** 2026-09-12 ｜ **연동** `scripts/google_form_sync.gs` → Supabase `partners`

협력사가 채우는 폼이다. 목표 소요 **3분 이내**.

---

## 읽는 법

각 문항을 아래 세 가지로 나눠 적었다.

| | 구글폼에서 |
|---|---|
| **질문** | 문항 제목 칸에 넣는다 |
| **설명** | 「설명」을 켜서 그 칸에 넣는다. 안 넣어도 되고 고쳐도 된다 |
| **형식** | 단답형 / 장문형 / 객관식 중 무엇인지 |

**`[일치필요]` 가 붙은 질문은 글자 하나까지 그대로 써야 한다.**
연동 스크립트가 제목으로 답을 찾기 때문이다. 어긋나면 오류가 나지 않고
**그 항목만 비어서 저장된다.** 대신 Apps Script 실행 기록에 못 찾은 제목이
남으므로, 첫 제출 뒤 한 번 확인하면 바로 알 수 있다.

설명과 예시는 자유롭게 바꿔도 된다. 제목만 맞으면 된다.

> 아래 `## 1.` `## 2.` 는 **이 문서의 절 번호**이지 문항 제목이 아니다.
> 폼 제목에 번호를 붙이면(`1. 확인 코드`) 스크립트가 못 찾는다.

> **개인정보를 묻지 않는다.** 연락처·주소는 이미 알고 있어 받을 이유가 없고,
> 받아 두면 그 정보가 개발자 개인 구글 계정에 쌓인다.

## 0. 폼 설정

| | |
|---|---|
| 응답 수정 | **허용** |
| 로그인 요구 | **안 함** — 구글 계정이 없을 수 있다 |
| 이메일 수집 | **안 함** |

보낼 때는 **확인 코드를 미리 채운 링크**를 만들어 보낸다.

```
폼 편집 화면 우측 상단 ⋮  →  「양식 미리 작성」
  → 확인 코드 칸에 그 협력사의 invite_code 를 넣는다
  → 하단 「링크 복사」
```

> 메뉴 이름이 바뀌었다. 예전에는 「미리 채워진 링크 가져오기」였고
> 영문은 `Get pre-filled link` 다. 이 화면에서는 제출되지 않는다.

### 나중에 고칠 때는 같은 링크로 다시 제출한다

「응답 수정」을 켜 두지만, 이메일을 수집하지 않으므로 **협력사는 그 수정
링크를 제출 직후 화면에서만 받는다.** 창을 닫으면 다시 찾을 수 없다.

그래서 안내는 이렇게 한다 — **처음 보내드린 링크로 다시 제출하시면 된다.**

```
협력사가 다시 제출  →  새 응답이 들어옴  →  스크립트가 같은 행을 갱신
```

확인 코드가 같으므로 같은 협력사 행이 갱신된다. 응답 시트에는 이력이
쌓이지만 우리가 쓰는 것은 `partners` 의 현재 값이다. 스크립트가 빈 값으로
기존 내용을 지우지 않으므로, 일부만 고쳐 내도 나머지는 남는다.

> **확인하지 못한 것** — 수정 링크로 들어가면 미리 채운 확인 코드가 그대로
> 남는지는 실제로 제출해 봐야 안다. 첫 제출 때 함께 확인한다.

### 섹션을 여섯으로 나눈다

SNS 를 안 하시는 분께 「주로 올리시는 것」을 묻지 않으려면 섹션 분기가
필요하다. 구글폼은 **객관식 문항의 답에 따라 다른 섹션으로 보낼 수 있는데,
그 문항이 섹션의 마지막에 있어야 한다.**

**섹션 제목과 설명은 스크립트와 무관하다.** 연동은 문항 제목만 보므로
자유롭게 바꿀 수 있다. 아래는 실제로 만든 것을 옮겨 둔 것이다.

### 섹션 1 — 협력사 질문

```
바틀링 협력사 입력 폼입니다. 아래 내용을 입력해 주세요.
예상 소요 시간은 약 3분입니다.

※ 나중에 가격 등이 변경되면 같은 링크에서 응답을 수정할 수 있습니다.
※ 별도의 연락처나 주소는 받지 않습니다.
```

문항 — 확인 코드 · 가게 이름 · 업종

### 섹션 2 — 지금 팔고 계신 메뉴

```
바틀링은 현재 판매 중인 메뉴를 구매해 판매합니다.
지금 판매하고 계신 메뉴를 적어주세요. 새로 만드실 필요는 없습니다.

```

문항 — 메뉴 1~5 (각 세 칸) · 그중 대표 메뉴

### 섹션 3 — 일정

```
일정 관련 질문입니다.
```

문항 — 납품 가능한 요일과 시간 · 협의 가능한 시간

### 섹션 4 — 홍보채널 (SNS) · 사용 채널

```
협력사의 SNS를 함께 활용해 제품을 더 효과적으로 홍보하고자 합니다.
알려주신 정보는 홍보 기획에 반영합니다.
```

문항 — 주로 쓰시는 SNS **(이 문항 하나만 둔다)**

### 섹션 5 — 홍보채널 (SNS) · 올리시는 형태

```
앞에서 고르신 채널에 주로 올리시는 형태를 알려주세요.
협업 때 부담이 크지 않은 형식으로 요청드리기 위한 것입니다.
```

문항 — 주로 올리시는 것 **(이 문항 하나만 둔다)**

### 섹션 6 — 제약 사항

문항 — 지켜야 할 조건

---

**분기 설정** — 섹션 4의 문항 우측 하단 ⋮ → 「답변을 기준으로 섹션으로
이동」을 켜면 선택지마다 갈 곳을 고를 수 있다.

```
인스타그램 ~ 카카오톡 채널  →  섹션 5
안 합니다                 →  섹션 6
```

섹션 5 아래의 「다음 섹션으로 진행」은 섹션 6으로 맞춰 둔다.

두 SNS 섹션에 같은 머리말을 붙인 것은, 분기 때문에 쪼개진 것이 협력사에게
한 덩이로 읽히게 하려는 것이다.

> **분기로 건너뛴 문항은 필수여도 통과된다.** 그래서 「주로 올리시는 것」을
> 필수로 두어도, SNS 를 안 하시는 분은 그 문항을 보지 않고 제출할 수 있다.

## 3. 지금 팔고 계신 메뉴

메뉴마다 세 칸을 따로 묻는다. 한 칸에 몰아 받으면 사람마다 적는 방식이 달라
옮겨 담을 때 깨진다.

### 메뉴 1

**질문** `메뉴 1` **[일치필요]**
**설명** 예: 붕어빵 3개
**형식** 단답형 · 필수

**질문** `메뉴 1 가격` **[일치필요]**
**설명** 손님에게 받으시는 값입니다. 숫자만 적어주세요. 예: 3000
**형식** 단답형 · 필수 · 응답 확인 `^[0-9,]+$`

**질문** `메뉴 1 납품가` **[일치필요]**
**설명** 바틀링에 주실 수 있는 값입니다. 정하지 못하셨으면 비워두셔도 됩니다.
**형식** 단답형 · 응답 확인 `^[0-9,]*$`

### 메뉴 2 ~ 메뉴 5

메뉴 1과 똑같은 세 칸을 숫자만 바꿔 만든다. **[일치필요]**

```
메뉴 2      메뉴 2 가격      메뉴 2 납품가
메뉴 3      메뉴 3 가격      메뉴 3 납품가
메뉴 4      메뉴 4 가격      메뉴 4 납품가
메뉴 5      메뉴 5 가격      메뉴 5 납품가
```

메뉴 1~3은 필수, 메뉴 4~5는 선택으로 둔다.

> **띄어쓰기까지 같아야 한다.** 스크립트가 `메뉴 ` 뒤에 숫자를 붙여 찾는다.
> `메뉴1` 이나 `메뉴 1번` 은 못 찾는다.

> **납품가를 메뉴마다 받는 이유.** 메뉴마다 원가가 다르다. 매장에 단가
> 하나만 두면 어떤 메뉴에서는 소매가보다 비싸게 매입하는 값이 나온다.
> 선택 항목이라 안 적으시면 그 메뉴의 매입가는 협의로 정한다.

> **가격 칸에 응답 확인을 거는 이유.** "3000원"이나 "삼천원"이 들어오면
> 숫자로 바꿀 수 없다.

---

**질문** `그중 대표 메뉴` **[일치필요]**
**설명** 가장 많이 나가는 것 하나를 적어주세요.
**형식** 단답형

## 4. 일정

**질문** `납품 가능한 요일과 시간` **[일치필요]**
**설명** 예: 화~일 오전 중 가능합니다. 월요일은 휴무입니다
**형식** 단답형 · 필수

> 실행일을 정하는 데 쓰인다. 만드는 날과 가져다주는 날이 맞아야 하므로,
> 어느 요일 어느 시간대에 납품이 가능한지를 묻는다.
>
> 「제약 사항」과 겹쳐 보이지만 층이 다르다. 이쪽은 평소 되는 범위이고,
> 저쪽은 지키지 못하면 기획이 성립하지 않는 것이다.

---

**질문** `협의 가능한 시간` **[일치필요]**
**설명** 전화나 방문으로 이야기 나누기 편하신 때를 적어주세요.
예: 평일 오전 / 브레이크타임 15~17시
**형식** 단답형 · 필수

> 납품 가능 시간과 다르다. 물건을 가져다주실 수 있는 때와 전화를 받으실
> 수 있는 때가 다르다. 매입가와 납품 수량은 결국 만나서 정해야 하므로
> 이 값이 있어야 약속을 잡을 수 있다.

## 5. SNS

> 이 절에서 알고 싶은 것은 둘이다. **어디에 올리시는지**, 그리고
> **무엇을 올려달라고 요청할 수 있는지**. 그 밖에는 묻지 않는다.

### 섹션 4 의 문항

**질문** `주로 쓰시는 SNS` **[일치필요]**
**설명** 여러 곳을 하시면 **가장 자주 올리시는 한 곳**만 골라주세요.
협업 때 그 채널에 한 번 올려주시는 것을 부탁드릴 예정입니다.
**형식** 객관식 · **필수** (하나만 선택)

**선택지도 글자 그대로 써야 한다 [일치필요]**

```
인스타그램        →  섹션 5
블로그            →  섹션 5
틱톡              →  섹션 5
유튜브            →  섹션 5
페이스북          →  섹션 5
카카오톡 채널      →  섹션 5
안 합니다         →  섹션 6
```

> **필수로 둔다.** 「안 합니다」가 있으므로 누구나 답할 수 있다.
> 비워 둘 수 있게 하면 안 하시는 것인지 아직 안 적으신 것인지 구분할 수
> 없고, (3)이 협력사에 홍보를 요청할지 판단하지 못한다.
>
> **단답형이 아니라 객관식으로 둔다.** 자유 입력이면 "인스타"·"인스타그램"
> ·"IG" 가 섞여 들어오는데, 그 값이 그대로 프롬프트에 실려 (3) 마케터가
> 홍보 채널을 정하는 근거가 된다.
>
> **여러 개를 받지 않는다.** 이 값으로 하는 일은 협력사에 게시물 하나를
> 요청하는 것이다. 채널이 여럿이면 요청도 늘어나는데, 협력사에 부담이
> 큰 요청은 하지 않기로 했다 (p3 규칙 10).
>
> 「안 합니다」를 고르시면 (3)이 **협력사에 홍보를 요청하지 않는다.**
> 판매가 바틀링 매장에서 이뤄지므로 협력사 매장에 게시물을 붙여 얻는 것이
> 불확실하고, 없는 채널을 대신할 것을 만들면 부담만 늘어난다.

### 섹션 5 의 문항

**질문** `주로 올리시는 것` **[일치필요]**
**설명** 위에서 고르신 채널에 주로 올리시는 형태를 골라주세요.
**형식** 객관식 · **필수** (하나만 선택)

**선택지도 글자 그대로 써야 한다 [일치필요]**

```
릴스
피드
스토리
숏츠
영상
글
```

> 플랫폼마다 쓰는 형식이 다르다. 인스타그램은 릴스·피드·스토리,
> 틱톡·유튜브는 숏츠나 영상, 블로그는 글이다.
>
> 이 값으로 (3)이 무엇을 만들어 달라고 할지 정한다. 릴스를 주로 만드는
> 곳에 피드 게시물을 요청하면 협력사가 부담스러워한다.

## 6. 제약 사항

**질문** `지켜야 할 조건` **[일치필요]**
**설명** 지켜야 할 조건을 한 줄에 하나씩 적어주세요.
적어주신 조건을 모두 지켜서 기획을 만듭니다.
특별히 없으시면 「없음」이라고 적어주세요.
**형식** 장문형 · 필수

**예시 (placeholder)**

```
한 번에 50개까지만 만들 수 있습니다
당일 만든 것만 드릴 수 있습니다
받아서 다시 데우거나 조리하시면 맛이 변해 안 됩니다
저희 상호를 표기해 주셔야 합니다
```

> **가장 중요한 문항이다.** 하드 제약으로 쓰여 이것을 지키지 못하는 안은
> 폐기된다.
>
> **「안 되는 것」으로만 묻지 않는다.** 「~는 안 됩니다」도 오고
> 「~여야 합니다」도 온다. 제목을 한쪽으로 몰면 다른 쪽을 안 적는다.
>
> **일정과 겹치지 않게 안내한다.** 「주말은 어렵습니다」 같은 것은 앞의
> 「납품 가능한 요일과 시간」이 받는다. 이쪽은 수량 한계·보관 조건·취급
> 방법·표기처럼 지키지 못하면 기획이 성립하지 않는 것들이다.
>
> **제목을 「안 되는 것」으로 쓰지 않은 이유가 여기에 있다.**
> 「지켜야 할 조건」이면 금지와 요구가 둘 다 담긴다.
>
> **「없음」도 답이다.** 비워 두면 조건이 없는 것인지 아직 안 적은
> 것인지 구분할 수 없다. 「없음」이라고 적어 주시면 확인된 사실로
> 다루고, 비어 있으면 「데이터 없음」으로 넘긴다.

## 묻지 않는 것과 그 이유

| 항목 | 왜 뺐나 |
|---|---|
| 보유 식재료 | 완성품을 사 오므로 무엇으로 만드시는지는 우리 일이 아니다 |
| 협업 가능 형태 | 완제품 매입 하나로 정해져(기획서 6-1) 고를 것이 없다 |
| 연락처·주소 | 이미 알고 있다. 받아 두면 개인 구글 계정에 남는다 |
| 팔로워 수 | 도달을 측정하지 않으므로 목표를 세울 수 없다. 무엇을 요청할지는 「주로 올리시는 것」이 정한다 |
| SNS 계정 이름 | 기획에 쓰이지 않는다. 필요하면 대표님이 직접 물으신다 |
